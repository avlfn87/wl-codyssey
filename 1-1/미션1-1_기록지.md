- 지피티 / 주요 대화 캡처 파일명: '지피티 캡쳐본'
- AI가 물어서 내가 정한 것: 사용자, 핵심동작, 데이터를 가져오는 방식, 개발방식, 포스터의 모양, 이미지 다운로드 모습, 이미지 업로드 제한, 티어리스트 가로길이 처리방식
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과): 이미지 업로드 제한 방식에 대해 미리 이야기를 나눈 네이토의 경우, 기획서에 '10개 내외 업로드~' 라고 작성하고 30개의 제한을 둔 반면, 제미나이는 기획서에 적힌 '10개 내외 업로드~' 라는 워딩을 통해 '이미지 10개 이내 업로드 제한' 으로 이해하고 작업을 수행함. 인간이 생각하는 '내외' 라는 개념은 인공지능에게 없다는 점과 네이토가 기획서에 작성한 내용과 실제로 이해하고 이행하려고 하는 내용과는 다르다는 점을 알았다.
- 선택한 파일명과 고른 이유: 영화_지피티_수정1 / 고른 이유는 네이토가 확실히 말한 내용만 이행해서 웹페이지를 작성했다는 점에서는 높게 평가한다. 긴 대화를 통해 '작업자가 명령한 내용 이외에 자체적으로 추가하면 안된다' 라는 사항을 입력했어서 html 파일을 만들 때에도 적용된 것 같다. 하지만 선택한 컨셉 자체가 '깔끔함'이 초점이 아닌 '빈티지' 를 선택한 작업이며 지피티가 마음대로 추가한 요소가 생각보다 빈티지함과 어울려서 지피티의 작업을 더 괜찮게 생각했다.
