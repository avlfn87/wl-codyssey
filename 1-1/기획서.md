# 🎬 영화 티어리스트 웹사이트 기획서

## 1. 누가 쓰나 (Target)
- 자신의 영화 관람 기록을 시각적으로 정리하고 소장하고 싶은 불특정 다수의 개인 사용자

## 2. 무엇을 하려고 (Goal)
- 사용자가 직접 업로드한 영화 포스터 이미지를 활용해 S, A, B, C, D 등급의 티어리스트 제작
- 제작한 티어리스트를 별도의 제목 텍스트 없이 이미지 파일로 저장

## 3. 화면과 동작 (Screen & Interaction)
- **디자인 테마**: 고전 영화관 느낌의 빈티지(Vintage) 스타일
- **이미지 업로드**: 로컬 기기에서 이미지를 선택하여 대기열에 추가 (최대 10개 내외 권장)
- **카드 형태**: 실제 영화 포스터와 유사한 세로가 긴 직사각형 형태
- **드래그 앤 드롭**: 대기열의 카드를 S, A, B, C, D 각 티어 행으로 자유롭게 이동 및 배치
- **반응형 레이아웃**: 티어 내 카드가 많아질 경우 화면 너비에 맞춰 자동으로 다음 줄로 줄바꿈(Wrap) 처리
- **저장 기능**: '이미지 저장' 버튼 클릭 시 티어리스트 영역만 캡처하여 다운로드

## 4. 필요한 자료 (Resources)
- **기술 라이브러리**: 드래그 앤 드롭 구현용 라이브러리, 화면 캡처용 라이브러리
- **디자인 자산**: 빈티지 테마용 배경 이미지 및 폰트
- **[미정 항목 - 개발 시 확정 필요]**:
  - 구체적인 폰트 종류 (오픈 소스 폰트 중 선택 예정)
  - 배경에 사용할 구체적인 이미지 소스
  - 상세 색상 코드(HEX)

## 5. 완성 기준 (Definition of Done)
- [ ] 10개 내외의 이미지를 업로드하고 관리할 수 있는가?
- [ ] 업로드된 이미지가 세로형 직사각형 카드로 표시되는가?
- [ ] S, A, B, C, D 등급 칸 사이로 카드를 드래그하여 배치할 수 있는가?
- [ ] 화면 너비에 따라 카드가 자동으로 줄바꿈되는가?
- [ ] 제목 없이 티어리스트 결과물만 이미지 파일로 저장되는가?
