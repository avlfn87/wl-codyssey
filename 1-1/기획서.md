# 🎬 Vintage Movie Tier Maker 기획서

## 1. 프로젝트 개요
- **프로젝트 명**: Vintage Movie Tier Maker
- **목적**: 사용자가 직접 영화 포스터 이미지를 업로드하고, S~D 등급의 티어리스트를 시각적으로 구성하여 이미지 파일로 저장하는 서비스
- **핵심 가치**: 빈티지한 영화관 감성의 디자인과 직관적인 드래그 앤 드롭 경험 제공

## 2. 사용자 정의 및 제약 사항
- **대상**: 자신의 영화 관람 기록을 시각적으로 정리하고 소장하고 싶은 모든 사용자
- **업로드 규모**: 한 번의 리스트 작성 시 **10개 내외**의 이미지 업로드 및 관리
- **데이터 저장**: 별도의 서버 저장 없이, 작성 중인 데이터는 브라우저 메모리 내에서만 유지 (이미지 다운로드로 최종 결과 소장)

## 3. 주요 기능 및 동작 (Features)
- **이미지 업로드**: 로컬 기기의 이미지 파일을 선택하여 대기열(Pool)에 추가
- **드래그 앤 드롭**: 대기열의 영화 카드를 S, A, B, C, D 등급 행으로 자유롭게 이동 및 배치
- **고정 티어 시스템**: 수정 불가능한 5단계(S, A, B, C, D) 등급 구조
- **반응형 레이아웃**: 각 티어 행 안에서 카드가 많아질 경우, 화면 너비에 맞춰 자동으로 다음 줄로 줄바꿈(Wrap) 처리
- **이미지 저장**: 추가적인 제목 텍스트 없이, 현재 구성된 티어리스트 영역만 깔끔하게 이미지 파일로 다운로드

## 4. 디자인 가이드 (Design)
- **전체 스타일**: 고전 영화관 느낌의 빈티지 스타일
  - **배경/요소**: 짙은 붉은색 커튼 질감, 바랜 종이 느낌의 텍스처, 필름 스트립 요소 등
- **영화 카드**: 실제 영화 포스터와 유사한 **세로가 긴 직사각형** 형태
- **폰트**: 레트로한 느낌의 세리프체 또는 클래식한 타이포그래피

## 5. 기술적 요구사항 (Technical)
- **인터페이스**: 마우스 드래그 앤 드롭 구현 (SortableJS 등 라이브러리 활용)
- **이미지 처리**: Canvas API 또는 html2canvas 라이브러리를 이용한 이미지 캡처 및 저장
- **레이아웃**: Flexbox를 이용한 유연한 카드 배치 및 줄바꿈 처리

## 6. 완성 기준 (Definition of Done)
- [ ] 10개 내외의 이미지를 업로드하고 원활하게 관리할 수 있는가?
- [ ] 업로드된 카드가 세로형 직사각형으로 올바르게 표시되는가?
- [ ] S~D 등급 칸 사이로 카드를 자유롭게 이동할 수 있는가?
- [ ] 화면 너비에 따라 카드가 자동으로 다음 줄로 넘어가는가?
- [ ] '다운로드' 버튼 클릭 시 추가 제목 없이 리스트 영역만 이미지로 저장되는가?
